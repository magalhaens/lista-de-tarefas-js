# Lista de Tarefas Simples

Este é um projeto simples de lista de tarefas desenvolvido com **HTML, CSS e JavaScript**.

O objetivo do projeto é praticar conceitos básicos de JavaScript, como manipulação do DOM, eventos de clique, validação de campos, criação de elementos na tela e atualização de contador.

## Funcionalidades

- Adicionar uma nova tarefa
- Validar se o campo está vazio
- Exibir as tarefas na tela
- Contar o total de tarefas criadas
- Limpar o campo após adicionar uma tarefa
- Focar novamente no input após criar a tarefa

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## O que aprendi com este projeto

Neste projeto, pratiquei:

- `document.querySelector()`
- `addEventListener()`
- `.value`
- `.trim()`
- `if` e `else`
- `createElement()`
- `appendChild()`
- `.textContent`
- Arrays
- Contador de tarefas
- Manipulação básica do DOM

## Como funciona

O usuário digita o nome de uma tarefa no campo de texto e clica no botão **Criar**.

Se o campo estiver preenchido, a tarefa é adicionada na tela e o contador é atualizado.

Se o campo estiver vazio, o sistema exibe um alerta pedindo para inserir uma tarefa.
